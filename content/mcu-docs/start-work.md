## 分析问题

仪表故障指示灯是整车最直观的故障初判依据，快速区分故障严重等级，缩小排查方向：

无故障灯但体感异常：仅顿挫、低速啸叫等 NVH / 驾驶性问题，属于性能优化类问题，无致命故障码。

同步记录灯点亮时机：上电、起步、高速巡航、能量回收、坡道等不同场景。

### step2 确认问题发生具体工况

锁定故障触发边界，固定工况才能稳定复现故障，完整记录 4 类关键条件：

1. 车速区间
2. 扭矩区间：小扭矩匀速、大扭矩急加速、负扭矩能量回收、坡道驻车；
3. 环境条件：零下低温、高温满载、电池高低 SOC 区间、长时间连续行驶；
4. 硬件约束：满载爬坡、快充后行驶、高低温静置后冷启动。例：故障仅低速小扭矩触发，可直接锁定谐波补偿、零速 FOC 控制模块。

### step3 还原驾驶员完整操作流程

故障触发与人为操作时序强相关，完整记录操作步骤，还原故障发生路径：

1. 动力操作：缓踩电门、急加速、松踏板滑行、踩刹车能量回收、坡道启停；
2. 模式操作：经济 / 运动驾驶模式切换、D/R 倒车档位切换；
3. 点火操作：冷车上电、行驶中途下电重启、TBOX 远程启动车辆、哨兵模式开启。

### step4 调取原始数据，分层定位根因

结合前三步收集的现象，采集完整日志数据，由整车到硬件分层拆解定位根源：

1. 整车交互层：核对DTC 故障触发前后数据，排除 VCU/BMS 等外部因素；

2. 应用控制层：分析扭矩斜坡、回收过渡、谐波补偿、高温降功率曲线波形；

3. 底层驱动层：检查电流环 PI 参数、旋变观测算法、SVPWM 调制、硬件保护触发逻辑；

4. 硬件物理层：核查低压线束、传感器、功率器件、高压回路，排除接线虚接、元器件损坏。

整改后全边界工况复测，留存变更前后数据对比；

全部分析过程、测试记录同步录入平台管理表 ，上传完整分析报告完成归档闭环。
