## 电驱系统及其外部交互

### 电驱系统是什么

**1. 电驱系统定义**

驱动电机系统是直接将电能转换为机械能的部分，决定了电动汽车的性能指标。驱动电机系统由驱动电动机和驱动电机控制器及冷却系统构成，通过高低压线束、冷却管路，与整车其他系统作电气和散热连接。

![这张图片展示了一辆银灰色的纯电SUV的外观示意图，图中用两处蓝色图形标记出汽车的前后位置，对应的就是文档中提及的前后电驱在整车里的布设位置，该内容用于辅助说明电驱系统在车辆上的具体布局，和文档中“前后电驱在整车中的位置”这一描述形成对应，能帮助理解电驱系统在整车中的布设情况。](https://feishu.cn/file/C10BbnsvYoLKNmxBFe3cphqbnzd)

前后电驱在整车中的位置

**2. 电驱系统三大核心硬件组成**

完整电驱总成包含**电机控制器 MCU、驱动电机、减速器**三大部分，一体化集成后称为电驱桥：

**2.1 电机控制器（MCU）**

<cite doc-id="Jm9pbA5eMogaq9xCi3Lc0s6jnhe" file-type="file" title="车用电机及控制相关介绍V1.0.pptx" type="doc"></cite>

<cite doc-id="OL0Ms18ONlYtnIdArKwcqgbLnKe" file-type="slide" title="电机控制器硬件培训材料V1.0" type="doc"></cite>

**2.2 电机本体**

分为永磁同步电机 PMSM和异步感应电机：

- 正向驱动：接收 MCU 三相交流电，产生电磁转矩，经减速器驱动车轮；
- 回馈发电：松油门 / 刹车时车轮反向拖动电机，切割磁感线产生交流电，实现能量回收；
- 配套传感器：旋转变压器（反馈转子角度）、定子温度传感器。

**2.3 减速器**

相当于燃油车变速箱，固定减速比：

- 放大电机扭矩：电机高转速小扭矩，经减速增扭，满足车辆起步、爬坡需求；
- 匹配转速区间：降低电机输出转速，适配车轮行驶转速范围；
- 集成附件：集成差速器、润滑油冷却回路。

### 整车级信号与接口

**1. 低压电源接口**

- **KL30 常电**：蓄电池持续供电，车辆 OFF 休眠档仍带电，用于故障码存储、诊断时钟保持、远程唤醒，不受点火开关控制；
- **KL15 点火使能电**：蓝牙钥匙，开车门等动作上电，锁车下电后切断；

**2. 通信接口：**

（1）CAN/CAN FD 整车总线**（3.1.3相关内容）**

MCU 挂载energy或motion **网段（3.1.1相关内容）**，周期收发报文完成跨控制器信息交互：

- MCU 接收报文（整车输入）：VCU 扭矩请求、BMS 功率限制、ESP 防滑扭矩约束、高压预充完成、充电使能信号；
- MCU 发送报文（对外输出）：实际输出扭矩、电机转速、IGBT / SiC/定子温度、母线电压电流、故障码、...；
- 交互对象：VCU、BMS、IPB等等。

（2）UDS 接口**（3.1.1可得到接口与网段对应关系）**

复用 CAN 总线作为诊断通道，覆盖三大应用场景：

- 工厂 EOL 下线检测：软件刷写、零部件编码写入等**（3.1.2相关内容）**；
- 售后维修：读取 DTC 故障码、故障快照、采集实时运行数据，清除故障存储；
- 研发标定测试：读写标定参数、录制总线和内部数据。

**3. 高压功率接口**

整车高压能量流转载体，配备高压互锁安全回路：

- 直流母线接口：连接动力电池正负极，输入高压直流电；

部分电机集成高压互锁 HIL，线束脱落、外壳开盖立即锁止功率输出；

- U/V/W 三相交流输出：输出正弦交流电驱动电机，制动回收时反向导入电机反电动势；
- 预充 / 主动放电回路：预充防止上电瞬间母线电容冲击；故障 / 下电时主动放电，释放母线残余高压，保障维修安全。

### 状态机管理

**1. 整车状态跳转**

整车点火档位信号驱动 MCU 逐级状态跳转，每个状态对应固定供电、高压、通讯、扭矩输出规则：

## 关注哪些指标

### 驾驶性

驾驶性指代驾驶员主观感受到的车辆动力响应、平顺程度，由MCU、VCU、IPB等ECU共同控制，部分指标均可通过 CAN 总线采集信号量化评判。

- **响应类：**

1. **扭矩响应延迟**VCU 整车控制器下发扭矩请求报文 → MCU 输出实际扭矩的时间间隔若延迟超标会出现 “踩电门不走车” 的拖沓感。
2. **扭矩爬升/回落斜率**起步、急加速时扭矩上升斜率决定车辆闯动感；松油门、能量回收介入时扭矩下降斜率影响滑行平顺性。斜率过大易窜动顿挫，斜率过小动力体感绵软
3. **能量回收切换响应**松踏板、踩刹车时正向驱动扭矩与负向回收扭矩切换的过渡延迟

- **平顺性类**

1. **匀速抖动**
2. **加减速顿挫**
3. **零速蠕行平稳性**0\~10km/h 低速蠕行、坡道驻车防溜工况

### 4.1 坐标变换基础

- Clarke变换（3s->2s）

**核心定义**

Clarke 变换又称**克拉克变换**，是将电机三相定子绕组（a,b,c 三相，轴线互成 120∘ 电角度，属于**三相静止坐标系**，记为 3s）中的电流 / 电压变量，转换为两相正交静止坐标系（α−β 坐标系，α 轴与 a 轴重合，β 轴垂直于 α 轴，属于**两相静止坐标系**，记为 2s）中的等效变量。

**变换约束**

为保证变换前后电机定子产生的**合成磁动势不变**，变换需遵循 “功率不变” 或 “幅值不变” 原则，工程中常用**幅值不变原则**，其电流变换矩阵为：

![图片展示的是三相坐标系下的电流变换矩阵。矩阵中包含ia、ib、ic三个变量，对应α、β、γ三个坐标轴。其中，ia与α坐标轴的系数为1，与β坐标轴的系数为0；ib与β坐标轴的系数为1，与α坐标轴的系数为0；ic与γ坐标轴的系数为1，与α、β坐标轴的系数均为0。该矩阵用于将三相变量（ia,ib,ic）简化为两相变量（iα,iβ），在电机控制中起到降维简化作用，降低控制算法计算复杂度。](https://feishu.cn/file/Pr5GbUgEtoeLDYxQhiRcvLf3nOb)

**核心作用**

（1）**降维简化**：将三相变量（ia,ib,ic）简化为两相变量（iα,iβ），大幅降低控制算法的计算复杂度。

（2）**过渡桥梁**：为后续 Park 变换提供适配的两相变量，是实现矢量控制的第一步。

- Park变换（2s->dq旋转坐标系）

**核心定义**

Park 变换又称**派克变换**，是将 α−β 两相静止坐标系中的电流 / 电压变量，转换为 d−q **两相旋转坐标系**中的等效变量。其中整个 d−q 坐标系随转子**同步旋转**，旋转速度等于转子的电角速度。

d 轴：与电机转子永磁体的磁场方向**重合**；

q 轴：超前 d 轴 90° 电角度；

**变换约束**

同样遵循**合成磁动势不变**原则，其电流变换矩阵由转子位置角 θ（d 轴与 α 轴的夹角）决定：

**核心作用**

这是实现电机解耦控制的**核心步骤**。在电机稳态运行时：

（1）三相定子电流是**交变的正弦波**，经过 Clarke+Park 变换后，会转化为 d−q 轴上的**直流信号**；

（2）id 为**励磁电流**，决定电机定子磁场的强弱；iq 为**转矩电流**，直接决定电机输出扭矩的大小。这样就把交流电机的控制，转化为类似**直流电机的控制逻辑**—— 通过独立调节 id 和 iq，分别控制电机的磁场和扭矩，实现扭矩的快速、精准响应。

- 反Park变换

**核心定义**

反 Park 变换是 **Park 变换的逆过程**，作用与 Park 变换完全相反：将 d−q 旋转坐标系中经过调节后的**目标电压变量**（ud,uq），转换回 α−β 两相静止坐标系的电压变量（uα,uβ）。

### 4.2 磁场定向控制原理

- PI调节器设计：电流环是 FOC 的**内环**，实时性要求最高（执行周期 10–50kHz），其 PI 参数需结合电机数学模型与工程整定方法确定，常用方法有两种：（1）**基于电机数学模型的极点配置法**永磁同步电机 d/q 轴的电压方程可简化为：其中 Rs 为定子电阻，Ld/Lq 为 d/q 轴电感，ωe 为电角速度，ψf 为永磁体磁链。忽略反电动势与交叉耦合项（电流环带宽远高于电机电气频率时），电流环的开环传递函数可近似为**一阶惯性环节**。通过 PI 调节器的比例系数 Kp 和积分系数 Ki，将电流环的闭环极点配置到目标带宽（通常为开关频率的 1/5–1/10），实现 “无超调、快速响应” 的控制效果。该方法的优势是理论性强、参数整定精准，适合对控制性能要求高的场景。(2)**工程整定法（Ziegler-Nichols 法）**这是一种无需精确电机模型的经验整定方法，步骤如下：PI 调节器的**积分环节**用于消除静差（让实际电流精准跟踪目标电流），但当调节器输出达到逆变器电压限值（受直流母线电压约束）时，若积分环节仍持续累积，会导致**积分饱和**现象 —— 表现为电流超调量大、响应延迟，甚至引发电机抖动。抗积分饱和的核心是**限制积分环节的累积量**，常用处理方法有 3 种：(1)**积分分离法**：设定电流偏差阈值，当偏差大于阈值时，关闭积分环节，仅用比例环节调节（快速减小偏差）；当偏差小于阈值时，再投入积分环节（消除静差）。(2)**限幅积分法**：直接限制积分环节的输出范围，确保 PI 调节器的总输出不超过逆变器的最大电压指令，避免积分量过度累积。(3)**抗积分饱和反馈法**：将 PI 调节器的实际输出与限幅输出的差值反馈至积分输入端，当输出达到限幅时，通过反馈信号抵消积分作用，实现积分 “冻结”。在电机高速运行时，电压方程中的**反电动势、交叉耦合项**会成为电流环的主要扰动，仅靠 PI 调节器的反馈调节难以满足动态响应需求，需引入**前馈补偿**策略，核心是 “提前补偿扰动，减少 PI 调节器的负担”。常用的前馈补偿项包括：**反电动势前馈**：根据电机转速 ωe 和永磁体磁链 ψf，计算反电动势 Eq=ωeψf，并将其作为前馈量加入 q 轴电压指令中，抵消反电动势对电流的影响。**交叉耦合前馈**：根据 d/q 轴电流和转速，计算交叉耦合电压项（−ωeLqiq 和 ωeLdid），分别加入 d/q 轴电压指令，消除 d/q 轴电流的相互干扰。前馈补偿的加入可使电流环的动态响应速度提升 30% 以上，尤其适合车辆加速、爬坡等大扭矩动态工况。

- 空间矢量脉宽调制**扇区判断**：将反 Park 变换得到的目标电压 uα、uβ 代入判别式，确定 Vref 所在的扇区。例如，通过判断 uβ、3uα−uβ、−3uα−uβ 的正负，可划分出 6 个扇区。根据零矢量的分配方式，SVPWM 分为**七段式**和**五段式**两种实现方案，核心区别在于开关信号的切换时序：**七段式 SVPWM**零矢量 V0 和 V7 平均分配在 PWM 周期的首尾和中间，一个 PWM 周期内功率器件的开关次数为 6 次。其优势是**输出电流谐波含量低**，电机运行噪声小，是乘用车电机控制器的主流选择；缺点是开关次数多，功率器件损耗略高。**五段式 SVPWM**零矢量仅使用 V0 或 V7，一个 PWM 周期内开关次数为 4 次。其优势是**开关损耗降低 30%**，适合大功率、高开关频率的场景；缺点是电流谐波略高于七段式，需搭配滤波电路使用。**过调制技术**当调制比 M>1（调制比为目标电压幅值与最大输出电压幅值的比值）时，通过调整有效矢量的作用时间，牺牲输出电压的正弦度，换取更高的输出电压幅值，确保电机在弱磁扩速区域仍能输出足够扭矩。过调制模式下，电机电流谐波会略有增加，但可满足整车极限工况的动力需求。**死区补偿技术**死区时间是指逆变器上下桥臂开关信号的**延时时间**（通常为几微秒），用于防止上下桥臂同时导通。但死区时间会导致输出电压畸变，引发电流谐波增大、电机低速抖动等问题。死区补偿的核心是**根据电流方向，补偿死区时间带来的电压损失**：通过检测电机相电流的正负，判断功率器件的实际导通状态，然后调整 PWM 信号的占空比，补偿死区时间造成的电压偏差，确保输出电压与指令电压一致。
